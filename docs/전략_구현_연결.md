# DAY 1 전략과 DAY 2 구현의 연결

| DAY 1 설계 근거 | DAY 2 구현 | 확인 결과 |
| --- | --- | --- |
| 초기 용량만으로 수명 판단이 어려움 | ΔQ 기반 회귀, 초기 QD 보조 입력 | CV는 개선됐지만 B2에서는 초기 QD 관계가 유지되지 않음 |
| ΔQ 분산의 배치별 강한 상관 | 단일 분산 기준과 방전 4피처 비교 | 최종 CV 7.72%, 단일 기준 9.03%; 외부 B2 순위는 반대 |
| 온도·IR·충전 조건도 물리적으로 의미 있음 | state·policy·current 집합의 사전 지정 비교 | 개발 CV에서 추가 피처가 항상 유리하지 않음 |
| 소표본·다중공선성 | Ridge·ElasticNet 규제, 제한된 SVR·얕은 RF | 17개 사전 지정 모델·피처 조합 중 ElasticNet 선정 |
| 동일 정책 중복을 막아야 함 | DAY 1 고정 그룹 분리, 안쪽·바깥쪽 그룹 CV | 개발/hold-out와 모든 CV에서 정책·셀 중복 없음 |
| 미래 knee·전체 기록은 입력에서 제외 | 초기 summary 절단, 피처 허용 목록 | 미래 관측 변경에도 초기 피처 불변; 금지 컬럼 거부 테스트 |
| 지정 Batch 2로 평가 | 2018-02-20의 39개 셀 평가 | MAPE 43.45%, 논문 목표 대비 +34.35%p |
| Batch 3은 선택 추가 평가 | 동일 모델로 40개 평가 | MAPE 11.71%; 장수명 셀에서 과소 예측 |
| MAPE와 Gap을 같은 적합 조건에서 비교 | 개발 28개 적합 모델 고정 | Hold-out/B2/B3 모두 동일 모델; 36개 재적합 성능을 혼합하지 않음 |

DAY 1 후보 계열과 피처 방향을 유지하고, 기준선·규제 강도·튜닝 격자를 구현했다. 외부 결과를 확인한 뒤 최종 후보를 바꾸거나 새 피처로 같은 시험 성능을 재최적화하지 않았다.
